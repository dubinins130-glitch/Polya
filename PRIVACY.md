# Политика конфиденциальности расширения «Поля»

«Поля» помогает сохранять личные заметки к веб-страницам. Для работы расширения достаточно локального профиля Chrome.

## Какие данные обрабатываются

При сохранении заметки расширение записывает её текст, адрес и заголовок страницы, даты создания и изменения. Для заметки к выделению также сохраняются цитата, окружающий текст, позиция и технические сведения для восстановления привязки. Расширение может проверить наличие сохранённой цитаты при открытии страницы.

Для заметки к изображению сохраняются адрес или короткий отпечаток встроенного изображения, контекст для повторного поиска и небольшая локальная миниатюра. Если браузер запрещает читать пиксели изображения, после выбора пункта меню расширение может временно снять видимую область активной вкладки и вырезать часть выбранного изображения. Полный снимок страницы и оригинал изображения в заметку не записываются.

Расширение читает основной документ доступных HTTP(S)-страниц для обработки выделений и поиска сохранённых цитат. Оно не ведёт журнал посещений. В журнале «Полей» отображаются страницы, к которым есть сохранённые заметки.

## Где хранятся данные

Заметки находятся в IndexedDB расширения. Порядок сортировки журнала и сигналы обновления открытых интерфейсов хранятся в локальном хранилище Chrome для расширения. Расширение не отправляет эти данные разработчикам или сторонним сервисам. Аналитики, рекламы, учётных записей и облачной синхронизации в расширении нет.

## Управление данными

Вы можете просмотреть, отредактировать или удалить заметку из боковой панели и журнала. При экспорте Chrome сохраняет резервную копию JSON по вашему запросу. Файл содержит заметки и данные их привязки в открытом виде. Управление этой копией после сохранения остаётся у вас. Удаление расширения удаляет его локальные данные в Chrome. Скачанные копии можно удалить средствами операционной системы.

## Зачем нужны разрешения

Доступ к HTTP(S)-страницам нужен для кнопки рядом с выделением, восстановления подсветки и перехода к цитатам. Разрешение `sidePanel` открывает боковую панель Chrome. Разрешение `storage` позволяет сохранять небольшие настройки и обновлять открытые интерфейсы после изменения заметок.

Разрешение `contextMenus` добавляет пункт сохранения заметки к изображению. Разрешение `activeTab` используется для получения видимой части изображения по явной команде пользователя, когда прямое чтение пикселей запрещено браузером.
