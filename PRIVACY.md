# Политика конфиденциальности расширения «Поля»

«Поля» обрабатывают и хранят заметки в профиле Chrome на вашем устройстве.

## Какие данные обрабатываются

В каждой заметке хранятся её текст, адрес и заголовок страницы, даты создания и последней правки. Для цитаты «Поля» запоминают выделенный фрагмент, соседний текст и позицию. Эти данные помогают снова найти цитату, когда вы откроете страницу.

Для картинки «Поля» сохраняют адрес или короткий отпечаток встроенного изображения, сведения для повторного поиска и, если получилось её получить, миниатюру. Когда Chrome блокирует прямое чтение картинки, расширение может сделать снимок видимой части активной вкладки. Это происходит после выбора команды «Добавить заметку в Поля». Снимок используется в памяти, чтобы вырезать миниатюру выбранной картинки.

Для работы с выделением и поиска цитат «Поля» читают основной документ доступной HTTP(S)-страницы. В журнал попадают только страницы, к которым вы сохранили заметки.

## Где хранятся данные

Заметки лежат в IndexedDB. Порядок сортировки и сигналы для обновления журнала и панели хранятся в `chrome.storage.local`. Все эти данные остаются на устройстве. Для работы достаточно локального профиля Chrome. В «Полях» нет рекламы, аналитики и облачной синхронизации.

## Управление данными

Заметку можно открыть, исправить или удалить в боковой панели. По кнопке «Экспорт» Chrome скачивает JSON с текстом заметок и их привязками. Данные в этом файле открыты. При удалении «Полей» Chrome удалит данные расширения из профиля. Скачанный JSON хранится отдельно, его можно удалить как обычный файл.

## Зачем нужны разрешения

- Доступ к HTTP(S)-страницам нужен для кнопки у выделения, подсветки и перехода к цитате.
- `sidePanel` открывает боковую панель, а `storage` сохраняет сортировку журнала и помогает обновлять его после правки заметки.
- `contextMenus` добавляет команду «Добавить заметку в Поля» в меню картинки. `activeTab` даёт доступ к снимку видимой части вкладки после выбора этой команды, если прямое чтение картинки заблокировано.
